# Profi Monitor (Android)

Приложение следит за новыми заказами на profi.ru и присылает их в Telegram.
Переписано с https://github.com/dobrozor/parser_profiru (там Python + Playwright).

## Как работает
1. Вы входите в Profi.ru внутри приложения (WebView), приложение забирает токен сессии (cookie `prfr_bo_tkn`). Пароль нигде не хранится.
2. Служба на переднем плане каждые 45–110 секунд делает запрос к API Profi.ru.
3. Новые заказы проходят фильтры (возраст, стоп-слова) и уходят в Telegram с кнопкой «Откликнуться».
4. Если сессия истекла, приходит уведомление и сообщение в Telegram: нужно войти заново.

Фильтры заказов (категории, города и т.д.) настраиваются в самом Profi.ru. Используется ваш сохранённый фильтр.

## Сборка
Пуш в ветку `main` запускает GitHub Actions. Готовый APK появится в разделе Releases
и в артефактах запуска (Actions → Build APK).
